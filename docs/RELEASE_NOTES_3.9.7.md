# MakerGlance 3.9.7 model-card pills

Build 35 removes the two-pill limit from watched Dashboard cards. Each recorded nonzero change in likes, downloads, boosts, prints and saves can appear for the selected period. Positive print changes retain their emphasis. The Models grid also shows all five kinds of positive growth, instead of only prints and likes.

Both card types use an image area that grows with the badge stack at larger text sizes. Unknown metrics and zero changes do not create pills. Existing total and period figures below each image are unchanged.

This update preserves the 3.9.6 direct-message, inbox, performance-period and pointer-routing changes. No account, notification preference or local-library migration is introduced.
